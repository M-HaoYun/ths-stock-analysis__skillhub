# 模板约定（必须遵守）

> 由 SKILL.md 迁移维护（2026-09-05）：所有报告类 HTML 的共同视觉与纪律规范。SKILL.md 只在尾部引用本文件，不重复维护正文。**新增约定写在本文件末尾。**

- **主题**：浅色金融仪表盘（用户已否决深色大屏风格）；品牌深蓝 `#1f3a93` + 金色 `#c9a227`；涨 `#e5484d` / 跌 `#2fa36b`（A股红涨绿跌）；数字 `tabular-nums` 等宽。
- **百分比口径**：ROE/毛利率/同比增速等百分数指标，服务端返回值直接加 `%`（不乘 100）。
- **数据标注**：缺失标 `[MISSING]`、陈旧(>90d) 标 `[STALE]`、假设标 `[ASSUMED]`。
- **免责声明**：页脚必须含"本报告仅供研究参考，不构成个人投资建议"，并注明数据口径与模型输出标注。
- **命名**：个股 `{股票名称}_{YYYYMMDD}.html`；情绪 `市场情绪扫描_{YYYYMMDD}.html`；估值 `估值仪表盘_{名称}_{YYYYMMDD}.html`；**ETF 估值 `ETF估值仪表盘_{名称}_{YYYYMMDD}.html`**。
- **输出目录通用性（禁止个人路径）**：所有脚本输出目录 = 环境变量 `THS_WORKSPACE`（未设置=当前运行目录 `os.getcwd()`），**脚本/文档内禁止硬编码个人绝对路径**（如写死盘符目录 `C:\Users\<用户名>\...`）；历史教训：全部模板曾内置开发机路径作 BASE 默认值，随 skill 分发泄露用户目录（2026-09-05 已统一清理，全库扫描确认零残留）；数据文件引用一律用相对路径或 `os.path.join(BASE, ...)`。
- **报告期参数化**：个股模板用 `CONFIG.report_label` 等字段驱动，兼容年报/中报/一季报。
- **区块编号唯一性**：HTML 区块编号（01/02/03...）必须连续且唯一——生成后正则提取全部 `class="no"` 编号比对校验。
- **占位符唯一性**：同一占位符在模板中只能出现一次（轮动综述 vbadge 曾把 `__VERDICT__` 放在徽章+粗体两处导致"贵金属独强"重复显示）；需重复展示时用不同占位符。
- **零硬编码残留**：模板数据必须全参数化；**所有图表/区块下的解读性 insight 必须进数据区**（如 PE_NOTE/PB_NOTE/IND_NOTE/FC_NOTE），禁止写死在模板；换日期/换标的前 grep 旧日期/旧个股名清理（历史教训：龙虎榜 5 处、估值仪表盘 6 处硬编码残留）。
- **图表总结凸显**：凡图表/表格下方的总结性文字统一用 `.insight` 金色凸显样式（金色渐变底+💡+加粗），不要更重的强化样式。
- **校验时机与预览注入（2026-09-07 实测）**：报告被预览面板打开后，宿主会在磁盘 HTML 注入 `data-page-node-id` 等编辑属性并重排超长行——文件体积变大（实测生成 29344B → 磁盘 49035B）、行结构变化。**内容/残留校验必须在生成脚本写盘后立即执行（宽式断言：读入字符串 count 关键文本/区块 class 出现次数），不要用磁盘字节数或 `wc -l` 判断成品是否正常**；已注入节点属性不影响浏览器渲染，无需"修复"。
- **验证类结论行样式（2026-09-08，能力 #12 v1.1）**：单标的"验证结论"行用 `.vchk`（ok=绿底✅ / bad=红底⚠️，浅色底+细边框，勿用实心强色块）；"审计表"判定徽章用 `.pill`（小号圆角 ok/bad 两种）；新 tag 色在 `CLS` 字典 + CSS `.stag.x` **两处同步注册**（曾漏注册致样式缺失）。
- **可选区块缺省不渲染**：模板功能升级新增的"每卡 chk 行/★验证记录面板/EVID 列"等应做成**数据区缺省即不渲染**（`chk` 缺失跳过、`AUDIT_ROWS=[]` 面板为空、EVID 按数据长度循环），保证旧数据/旧脚本仍可渲染、增量升级不破坏向后兼容。
- **KPI「值+标签」成对进数据区（2026-09-10 修订）**：hero KPI 每格必须是 `xxx / xxx_k` 数据对（`strong/strong_k`、`pos_cnt/pos_cnt_k`、`pool/pool_k`），**标签禁止硬编码在模板**。轮动模板 v1.5 第 2 格标签写死"20日正收益板块"，09-10 普跌日填入"4 个"（当日红盘板块数）后出现**值与标签口径错配**（读起来像"20 日仅 4 个正收益"，实际当时有 17 个）。教训：凡随行情变化的展示文字都在数据区；渲染后必读一次 KPI 区，确认每个值与其标签口径一致（v1.6 已修复并加此校验步骤）。
- **涨跌红绿着色规范（2026-09-10，能力 #12 v1.2 用户明确要求）**：①**个股涨跌一律红涨绿跌，禁止硬编码类名**——卡片 `chg` 字段必须按数值正负自动判类（`chg_cls()`：`+`→`.up` 红、`-`→`.dn` 绿）；渲染曾把 `class="chg up"` 写死，导致下跌股也显红（v1.2 修复）。②数据格/技术指标格文本统一走 `hl()` 帮助函数，自动把文本里 `±x.x%` 包裹 `<span class="up|dn">`，无需逐字段手写颜色。③**涨停家数、封板率、连板高度等"市场热度"类指标一律用 `.hot` 红色**（语义=市场温度，**不受当日涨跌方向影响**；09-10 退潮日曾误填 `.dn` 显绿）；跌停/降温类用 `.dn` 绿。CSS 需同时定义 `.up{color:var(--red)} .dn{color:var(--green)} .hot{color:var(--red)}`。
- **短中线定位纪律（2026-09-10，能力 #12 v1.2 用户明确要求）**：选股类报告**一律短中线思维、不推长线**——持有周期口径 = **3~10 个交易日**（最长 20 个交易日）。每只必须给 ①入场技术位 ②止损位 ③短线目标/减仓条件；plan 首标"【3~10 个交易日】"，标签写"操作参考 · 短中线"，04 区块首行加"短中线持有，不做长线"纪律行，页脚写明"定位短中线，非长线推荐"。**禁止"长期持有/价值投资/穿越牛熊"表述**；基本面只作「短线不做接刀」的安全垫（破位即走，不因基本面转长线）。
- **短线技术指标区（2026-09-10，能力 #12 v1.2）**：选股报告每卡必须附 `tech`（6 格）+ `tnote`（研判句），数据**一律本地前复权 parquet 自算、不得凭印象**：MA5/10/20/60 排列 · RSI14 · MACD(12,26,9) · 量比（今量÷前5日均量）· 布林(20,2) %B · 关键位（支撑=MA5/10/20 或前低，压力=20日高/颈线）。判读纪律：**RSI>70 + %B>100 + 乖离 MA20>8% 三者同现 = 短线超买 → 操作写"回踩再参与"，不给追高**；技术面须与基本面互证（09-10 华正新材 乖离 MA20 +20.3%/%B 118/20日 +43% 独立佐证基本面否决，写入 AUDIT）。样式用 `.tgrid`（浅蓝底）+ `.tnote`（虚线分隔）。
